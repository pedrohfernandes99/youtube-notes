# YouTube Focus

A Chrome Extension (Manifest V3) built to turn YouTube into a distraction-free study tool. 

## 🚀 Features

- **📝 Timestamped Notes:** Save notes linked to the exact minute of the video. Click the timestamp to jump right back to that moment. Export all notes to Markdown.
- **🚫 Distraction Filters:** Instantly hide Shorts, comments, recommended videos, and end-screen cards directly from the popup.
- **⚡ Custom Speed & A-B Loop:** Control video playback speed from 0.25x to 3x and create custom A-B loops to repeat specific sections.
- **🌙 Zen Mode:** Hide the entire YouTube interface (header, sidebar, comments) and darken the background for ultimate focus.

## 🛠️ Technologies

- **JavaScript (ES2020)**, HTML, CSS
- Chrome Extensions API (Manifest V3, `chrome.storage`)
- Tested on **Google Chrome 109** (the last version compatible with Windows 7)
